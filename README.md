# Power BI Dashboard

## 概要
Adventure Works のデータを使用し、売上や利益、ブランド別・カテゴリ別の分析ができるダッシュボードを作成しました。

## 使用技術
* Power BI
* Power Query
* DAX

## 主な機能
* 売上・利益のKPI表示
* ブランド別売上分析
* カテゴリ別売上分析
* フィルターによるデータの絞り込み
* モバイル表示対応

## 工夫した点
* 重要なKPIを画面上部に配置し、一目で状況を把握できるようにしました。
* 色数を抑え、見やすいレイアウトを意識しました。
* グラフの配置を工夫し、データの比較がしやすいデザインにしました。
